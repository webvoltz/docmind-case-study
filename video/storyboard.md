# Walkthrough video: storyboard

**Format:** 1920 × 1080, 1:20, H.264 with AAC audio
**Narrator:** synthetic voice, calm and direct
**Audience:** business leads, not engineers. One message: answers from long documents that you can check.
**Script:** [`script.md`](script.md), with the time each scene starts.

## Look

| Element | Rule |
| --- | --- |
| Background | Blueprint blue (`#1C30C3`, deepening to `#122299` at the edges) with a faint drafting grid and corner crop marks |
| Chapter label | Top left, mono, `0N / 09` plus the chapter name |
| Headings | Heavy sans, sentence case, two lines, the key phrase highlighted in lime (`#D4FD3D`) |
| Panels | Off-white cards with a dark outline, the same "paper" UI the product uses |
| Captions | Word by word along the bottom, emphasis in lime |
| Progress | A 3 × 3 grid bottom right fills one cell per chapter |
| Motion | Calm springs. Each chapter starts on its line of narration. |

## Scenes
